DIE EINBINDUNG ZUM AUSPROBIEREN

Pinselia auf Ihrer Webseite.

Hier läuft die Figur über eine Script-Einbindung. Klicken Sie unten auf die Kunstmagierin oder ziehen Sie sie an eine andere Stelle.

1. Frei auf der Seite laufen

Diesen Code in den Bereich für eigenes HTML/JavaScript einfügen, idealerweise vor dem schließenden </body>:

<script src="https://galgental9ps-png.github.io/Atelier-Chatavatar-wo/avatar.js" defer></script>

Figur und Atelierwissen werden von GitHub Pages geladen.

2. Als eingebetteter Bereich

Wenn Ihr Baukasten nur eingebettete Seiten erlaubt, nutzen Sie diesen Rahmen. Die Figur bleibt dann innerhalb dieses Bereichs.

<iframe src="https://galgental9ps-png.github.io/Atelier-Chatavatar-wo/embed.html"
  title="Pinselia – Kunstbegleiterin" width="100%" height="740"
  style="border:0;max-width:100%"></iframe>

Bei IONOS hängt die freie Bewegung auf der gesamten Seite davon ab, ob der Editor das Script direkt im Seitendokument ausführt. Falls er es entfernt oder isoliert, verwenden Sie den Rahmen.
